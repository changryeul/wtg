# KRX FEP 시나리오 — 종목별 기대값 대사표

FEP 가상 시세 관측(`docs/krx-fep-observe.md`) 시 종목별로 web 클라이언트가 받아야 할
**기대 envelope 값**. 입력 시나리오는 `etc/krx-fep-scenario.json`, 기대 출력은 실제
`mci-edge-krx` 코드 경로(디코드+enrichment)로 산출 — C 오라클(`make verify-krx`)이 raw
파싱을 이미 검증하므로 **권위 있는 정답표**다.

> **실 FEP 값 정렬**: 아래는 대표 시나리오다. 실제 FEP 가 다른 종목/값을 쏘면
> `etc/krx-fep-scenario.json` 을 그 값으로 바꾸고 아래 §4 로 표를 재생성하면 된다.

## 2. 기대 체결 envelope (fut.trade / bond.trade)

전일대비 = `체결가 − 전일종가`(전일종가≤0 이면 기준가). 채권은 전일종가 TR 이 없어
**기준가 대비**(`yDiff`). 직전대비 = `체결가 − 직전가`(첫 체결이면 직전가 없어 0).

| 코드 | last | 전일대비 diff | 등락률 rate | sign | 직전대비 cdiff | csign | settle / finalSettle / cd |
|-----|-----|------|------|:--:|------|:--:|------|
| 101V6000 | 265.75 | **+0.25** | +0.0942% | + | +0.05 | + | 265.30 / 265.40 / 11 |
| 105V3000 | 265.20 | **−0.20** | −0.0754% | − | −0.05 | − | 265.15 / 265.20 / 11 |
| 201S3000 | 8.75 | **+0.15** | +1.7442% | + | +0.05 | + | — (옵션 정산 TR 없음) |
| 301S3000 | 6.10 | **−0.10** | −1.6129% | − | −0.05 | − | — |
| 167V3000 | 106.62 | **+0.12** | +0.1127% | + | +0.01 | + | 106.60 / 106.61 / 11 |
| KR103501GA31 | 10250.50 | **+10.50** ³ | +0.1025% | + | 0 ⁴ | (공백) | — |

³ 채권 전일대비는 `yDiff/yRate/ySign` 필드(기준가 10240 대비). JSON: `"yDiff":10.5,"yRate":0.1025,"ySign":"+"`.
   `diff/rate/sign`(직전대비)은 별도. 수익률 `yield`=3.125%.
⁴ 첫 체결이라 직전가 미보유 → 직전대비 0. 두 번째 체결부터 `cprc−직전cprc` 로 채워짐.

## 4. 표 재생성 + 실측 대사 (한 줄)

```bash
# 1) 시나리오 → 캡처
./build/bin/krx-verify scenario etc/krx-fep-scenario.json /tmp/fep.dat
# 2) mci-edge-krx 로 흘려 실제 enriched envelope 확인 (로컬 테스트 그룹)
./build/bin/mci-edge-krx --mcast --mcast-group 239.9.9.9 --mcast-ports 61099 --listen :8085 &
./build/bin/krx-tester --url ws://127.0.0.1:8085/v1/subscribe \
    --symbols 101V6000,105V3000,201S3000,301S3000,167V3000,KR103501GA31 --json --timeout 5s &
./build/bin/krx-verify replay /tmp/fep.dat 239.9.9.9:61099 2 25ms
# 3) 실 FEP 대사: FEP 를 실 그룹(227.10.20.10)에 송신시키고, mci-edge-krx --mcast(기본)로
#    같은 종목 구독 → 위 표와 값 비교 (docs/krx-fep-observe.md).
```

- 마스터(A006F/A001B)·정산(H306F)이 **체결보다 먼저** 도착해야 전일대비/정산가가 채워짐
  — scenario 생성기가 종목별로 master→settle→book→trade 순서로 emit 하므로 자동 보장.
- 부동소수 표시는 반올림 — JSON 원값은 `265.75/0.25/0.09416...` 처럼 배정도.

## 관련
- `etc/krx-fep-scenario.json` — 입력 시나리오 (FEP 값으로 교체)
- `docs/krx-fep-observe.md` — FEP 관측 절차 / `docs/krx-sise-design.md §11` — 정답지 대사
- `cmd/krx-verify scenario` — 시나리오→캡처 / `make verify-krx` — C오라클↔Go raw 대조
