Winway Trading Gateway · 시세 연동

한 소켓으로 FX와 KRX 시세를 구독한다

클라이언트가 단일 WebSocket으로 외환·선물·옵션·채권 시세를 함께 구독하고 받는 방법. v2 폴리모픽 envelope는 opt-in이라, 기존 연동은 그대로 두고 준비되면 전환하면 됩니다.

엔드포인트 mci-edge-price :8083 경로 /v1/subscribe 인증 JWT 활성화 ?ev=2
시작 3줄이면 붙는다
01 · 접속
인증 붙여 연결
JWT를 쿼리로, ev=2로 통합 형식 요청.

wss://HOST:8083/v1/subscribe?access_token=JWT&ev=2

02 · 구독
자산 섞어 요청
키는 symbols 하나. FX·KRX 함께.

{"type":"subscribe","symbols":["USD/KRW","101V6000"]}

03 · 수신
type로 분기
type·asset_class 보고 data만 파싱.

{"ev":2,"type":"fx.quote",…,"data":{…}}

아래는 그대로 붙여 쓸 수 있는 정확한 계약입니다. HOST·외부 포트는 DMZ/ingress·TLS 매핑에 따라 운영과 확인하세요.

인증 먼저 JWT

접속 & 인증

WebSocket은 브라우저에서 커스텀 헤더를 못 넣으므로 토큰을 쿼리로 전달합니다. ev=2를 붙이면 통합 형식, 생략하면 기존 형식(무영향).

JWT는 로그인(edge-api :8090 POST /v1/login)으로 발급받습니다. 로그인 시 Site/Tier→Profile이 토큰에 박혀, 클라이언트는 자기 Profile의 마진 적용 시세만 받습니다(위변조 불가).

메시지 받기

안정 헤더 6필드 + 자산별 data. 클라이언트는 type(또는 asset_class) 하나로 분기해 data만 파싱하면 됩니다 — 자산군마다 렌더가 다른 건 원래 그렇습니다.

type 판별자

typeasset_class내용
fx.quoteFX마진 적용 quote (bid/ask + raw)
krx.fut.tradeFUTURE선물 체결 (등락·정산 enrich)
krx.fut.bookFUTURE선물 호가 N단 배열
krx.fut.settleFUTURE선물 정산가
krx.fut.masterFUTURE선물 종목 마스터
krx.bond.tradeBOND채권 체결 (수익률)
krx.bond.bookBOND채권 우선호가
krx.bond.masterBOND채권 종목 마스터
마진 유무 = data 필드 유무. FX는 bid/ask(마진)+raw_bid/raw_ask(원본)를 싣고, 증권엔 이 필드가 없습니다. 클라이언트는 type으로만 분기하면 되고 마진을 특별 처리할 필요가 없습니다. ts_unix_nano는 KRX의 HHMMSS도 서버가 KST 절대시각으로 정규화해 통일합니다.

시스템 프레임(subscribed / error / stale / fresh)은 최상위 type만 있고 data가 없거나 최소입니다 — quote가 아닌 type은 제어 메시지로 처리하세요.

호환 안 바꿔도 됩니다

기존 방식 (ev 생략)

ev를 빼면 지금까지의 평면 형식 그대로 옵니다. 전환은 준비된 화면부터 점진적으로.

전환 체크리스트

클라이언트 마이그레이션

  1. KRX 구독을 :8085 → :8083으로 옮기고 JWT를 부착한다.
  2. WS URL에 ?ev=2를 추가하고, 구독 키를 pairs → symbols로 바꾼다.
  3. 수신부를 type switch → data 파싱 구조로 정리한다(자산군별 렌더 분기는 그대로).
  4. FX와 KRX를 WebSocket 하나로 합쳐 연결 수를 줄인다.
  5. 끊김 대비 자동 재연결 + 재구독을 넣는다(구독 상태는 클라이언트 책임).
